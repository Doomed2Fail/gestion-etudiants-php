Avec XAMPP : copier le dossier gestion_etudiants dans C:\xampp\htdocs, démarrer Apache, puis ouvrir http://localhost/gestion_etudiants/
La page test.php affiche la configuration PHP. Le fichier data/etudiants.txt doit être accessible en écriture.
Les photos sont enregistrées dans uploads. L'e-mail du bonus est ajouté en dernier champ dans le fichier texte ; les lignes à 6 champs restent lisibles.
Les statistiques reflètent la recherche validée avec le bouton Rechercher ; le filtrage instantané masque simplement les lignes visibles.
Compte et stockage simplifiés pour le TP, non destinés à une mise en ligne publique.
